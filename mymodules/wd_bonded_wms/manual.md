# 荷兰保税仓管理模块 (wd_bonded_wms) 使用手册

## 概述

本模块管理荷兰保税仓的全链路业务，覆盖进口货代口岸端到陆路转运、保税仓入库、仓内监管、出库再转运的完整流程。

### 核心功能

- T1/B3 海关申报管理 (SAD/C88 格式)
- 到仓登记与封志核验 (Gate Arrival)
- 保税入库/出库指令管理
- 保税库存属性与海关监管状态跟踪
- 核注核销记录与审计追溯
- 货值额度与担保管理
- 保税商品备案
- 监管日志 (不可篡改)

---

## 1. 基础配置

### 1.1 保税账册 (Bonded Book)

**路径：** 保税WMS > 基础数据 > 保税账册

保税账册是海关监管的核心档案，记录企业的保税资质和额度。

**必填字段：**
- **编号** — 系统自动生成
- **海关代码** — 例如 NLRTM
- **经营公司** — 保税仓库的运营企业
- **有效期起/止** — 账册的有效期

**操作流程：**
1. 新建账册，填写海关代码和经营公司
2. 设置有效期
3. 点击 **Activate** 激活账册
4. 在"货值额度"选项卡中配置额度上限

### 1.2 保税商品备案 (Bonded Product Filing)

**路径：** 保税WMS > 基础数据 > 保税商品备案

**必填字段：** 保税账册、产品、HS编码、申报单价

### 1.3 货值额度管理 (Value Limits)

**路径：** 保税WMS > 基础数据 > 货值额度

管理每个账册的货值上限，支持按品类设限，系统实时计算已用/可用额度。

---

## 2. 海关申报

### 2.1 海关文件 (Customs Declaration)

**路径：** 保税WMS > 海关申报 > 海关文件

四种申报类型：

| 类型 | 说明 |
|------|------|
| T1 进境 | 进口转运报关（口岸→保税仓） |
| B3 进境 | 保税入库申报（进入保税监管） |
| B3 出境 | 保税出库申报（离开保税监管） |
| T1 出境 | 出口转运报关（保税仓→口岸） |

**操作流程：**
1. 新建申报，选择类型
2. 填写申报信息：EORI、运输方式、货物信息
3. 填写申报行项：产品、HS编码、数量、价值
4. 点击 **Submit** 提交
5. **Approve** 通过 / **Reject** 驳回
6. 审批通过后 **Set to Done**

**前置条件 (B3进境)：**
- B3 需要 T1 前置条件时，在 Pre-conditions 选项卡录入前置 MRN

---

## 3. 仓库操作

### 3.1 到仓登记 (Gate Arrival)

**路径：** 保税WMS > 操作 > 到仓登记

**操作流程：**
1. 新建登记，关联 T1 进境申报
2. 填写集装箱号、封志号、运输信息
3. 上传封志照片
4. **Confirm Seal Intact** 确认封志完好
5. 封志损坏点击 **Report Seal Damaged**

### 3.2 保税入库 (Bonded Inbound)

**路径：** 保税WMS > 操作 > 保税入库

**流程：** 新建 → Confirm → Create Stock Picking → Start → Set to Done

### 3.3 保税出库 (Bonded Outbound)

**路径：** 保税WMS > 操作 > 保税出库

**流程：** 新建 → Confirm → Create Stock Picking → Start → Cancel

---

## 4. 保税库存

### 4.1 库存管理 (Bonded Stock)

**路径：** 保税WMS > 保税库存 > 所有保税库存

**海关监管状态：** Entrepot (保税中) / Vrij (已完税) / In T1 Transit (转运中) / RTO (退回) / Destroyed (已销毁)

支持按状态、锁定状态、账册、产品筛选。

### 4.2 核注核销 (Verifications)

记录库存监管状态的变更，实现海关追溯。核注类型覆盖所有状态转换路径。

### 4.3 每日快照 & 月度报表

系统定时任务自动生成 (每天 23:59 快照，每月初月报)。

---

## 5. 监控与审计

### 5.1 审计日志 (Audit Log)

记录所有关键操作，不可篡改。包括操作时间、操作人、操作类型、变更详情。

### 5.2 定时任务

| 任务 | 频率 | 说明 |
|------|------|------|
| 每日库存快照 | 每天 23:59 | 库存日快照 |
| 月度库存报表 | 每月初 | 库存月报 |
| T1超时监控 | 每6小时 | T1转运超期检查 |

---

## 6. 权限说明

| 用户组 | 权限 |
|--------|------|
| Bonded Customs - Declaration | 申报读写 |
| Bonded Customs - Review | 关务复核 |
| Bonded Warehouse | 仓库操作 (按仓库隔离) |
| Bonded Finance | 财务只读 |
| Bonded Administrator | 完全控制 |
| Bonded Customs - Audit | 海关审计只读 |
| Bonded Portal | 客户门户 (仅本公司) |

**Portal用户：** 只能查看本公司关联数据。
**仓管用户：** 只能查看本仓库的作业记录。
**管理员：** 可查看所有数据。

## 7. 常见问题

**模块安装后看不到菜单？**
为用户分配对应的用户组，或确认 `ir.model.access.csv` 中已添加 `base.group_system` 的访问权限。

**创建海关申报时找不到前置 MRN？**
只有 B3 进境需前置条件。先创建 T1 进境并完成到仓登记和关闭。

**库存锁定后如何解锁？**
取消对应的出库指令即可解锁。
